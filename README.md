# 连续对话接话

GCP 的读空气是概率制，连续对话中的追问偶尔被吞。本插件在概率判定前做一次
确定性判定，命中就把概率临时拉满，让 GCP 走正常流程回复：

1. **第二人称追问**：发送者注意力达标（最近和机器人互动过）且消息包含"你/您"等标记
2. **先戳后问**：戳过机器人后窗口期内的消息（GCP 的戳一戳响应不登记注意力，这里补上）

判定通过后由 GCP 正常生成回复（带上下文、表情包、分段等全套行为），本插件不自己说话。

## 依赖

- 需要安装并启用 [astrbot_plugin_group_chat_plus](https://github.com/Him666233/astrbot_plugin_group_chat_plus)（读空气插件）：本插件经 AstrBot 插件注册表动态定位其概率/注意力管理器，GCP 未安装或版本变动时自动停用，不影响其他功能。
- 支持平台：QQ（群聊）；网页测试台不参与判定。

## 对话收束（v0.3.0，防晚安循环）

互道晚安后没完没了地互相回晚安？本插件让对话能自然结束：

- 每轮请求会附带一条收尾指引：对话自然结束（互道晚安/再见、对方要休息、话题完整收尾）时，
  她的回复末尾会输出 `[[对话结束]]` 标记
- 系统检测到标记后**剥掉标记再发出**，并把该会话标记为“已收束”（默认 10 分钟）
- 收束期内，**同一对象的纯道别回声**（晚安/拜拜/嗯嗯/好的 这类 ≤12 字的短消息）直接忽略，不再触发回复
- **有新内容就立刻恢复正常**：带实质内容的消息、其他人发的消息、@ 都不受影响
- 关闭方式：`farewell_enabled=false`
